# Soft Kettlebell — 3 Kelebihan (vertical edit)

1080×1920, 60 fps, 59.25 s, built with HyperFrames 0.9.65.

## How it is built

| Layer | What | Where |
|---|---|---|
| Voiceover | Original `New Task` audio stream copied bit-for-bit (`-c:a copy`), full length, `data-volume="1"` | `assets/audio/voiceover.m4a` |
| Footage | 10 clips, one per sentence block, cut inside VO pauses; original sound at 30 % | `assets/footage/c01..c10.mp4` (`tools/prep_footage.sh`) |
| Zoom + flash | Each clip zooms 1.00 → 1.08 in 0.55 s; white flash (2 frames up, 0.2 s down) on all 9 cuts | `index.html`, `compositions/fx.html` |
| Graphics | One overlay per clip | `compositions/g01..g10.html` |
| Captions | Anton 60 px, uppercase, black stroke, 2–3 words, centre-bottom; active word yellow, keywords neon green | `compositions/captions.html` |
| SFX | Synthesised in code: whoosh ×3 takes, pop ×2, ding, impact, cha-ching, riser, zap | `tools/sfx.py` → `assets/sfx/` |
| No music | — | — |

Everything is generated by `python3 tools/build.py` (edit there, or edit the HTML directly in the HyperFrames desktop app).

## Checks done

- `hyperframes check`: 0 errors. Image credits are small on purpose (`data-layout-ignore`). One warning kept on purpose: contrast on the pink "3" of the hook title — it carries a 12 px black stroke, so it reads.
- Safe area: all graphics inside the TikTok + Reels + Shorts safe area (y 288–1248, x ≤ 780 in the lower band). Captions are centred as asked, so long groups reach under TikTok's right rail; marked `data-layout-allow-safe-zone`.
- Snapshots of every scene, the cut flash, and the end frame (CTA: button + "Harga tengah MURAH!" + arrows, no caption).
- VO sync: the rendered audio is compared against the original VO (see delivery note).
- Sound was measured, not heard. VO is −30 LUFS integrated (as delivered, untouched); SFX sit about 8–12 dB under it.
